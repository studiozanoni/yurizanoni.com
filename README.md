# yurizanoni.com — personal site, v2 (preview branch)

**Preview only. Do not merge into `main` until Yuri approves.** `main` is the live apex via GitHub Pages.

- Static HTML/CSS + a small `script.js` (HK clock, scroll reveal). No build step, no external requests.
- Typefaces (2): Host Grotesk + JetBrains Mono, latin subset, embedded in `fonts.css` (SIL OFL 1.1).
- Logo: `logo.svg` / `mark.svg`, redrawn as vector from the YZ mark in the International Business brochure.
- Portrait slot: the red panel in the hero (`.hero-mark`) is where Yuri's photo goes once supplied.
- International Business has its own section (`#international-business`) so prospects sent to yurizanoni.com land on the services.
